# Polyhedrals

This mod implements physically simulated tabletop dice. It is primarily designed as a library mod, intended to be used by other systems which want dice driven results.
Dice have multiple methods in which they can be used; real dice can be crafted and thrown at will. Virtual dice can also be spawned, which persist in the world on a timer.

## Developers

See [INTEGRATION.md](INTEGRATION.md) to throw dice, read results, or modify rolls from your own mod.
